## Implemented rendering and evidence

The original legacy geometry/shaders are retained, with only the old corridor draw range replaced. The new corridor is visible from every camera, not swapped at a camera threshold. Active scene 159,494 triangles; new corridor 128,000. Geometry includes actual bevels, swept round pipes/elbows, deep floor grates, wall bays and the flared exit required by the old route.

GGX/Smith/Schlick shading receives two cached 2048² geometric shadow maps with 4-tap comparison filtering. Environment illumination/reflections use six 128² HDR renders of actual corridor geometry and its lighting/shadows, 8 mip levels, 128-sample GGX prefiltering and room-box parallax correction. No external environment image or reference image is used at runtime.

Full-HD feature-off diagnostics of the SAME candidate establish actual contributions: disabling shadow lookup changes 7.167% of pixels(mean absolute RGB difference 0.223/255); disabling environment contribution changes 95.253%(mean3.189/255). These results prove mechanisms affect pixels; they do not establish convincing artistic shadows/reflections. The reviewer found those visible effects insufficient.

The candidate has 91.77% of pixels below display-luminance 24/255; the reference has 60.51%. Mean display luminance is 0.04956 versus 0.09033. These descriptive measurements support the missing-light/highlight concern, not an artistic similarity score. Median luminance is similar; globally lifting black levels would not by itself recreate the reference's selective light hierarchy.

## Limits and stop condition

The local reflection probe is cached and approximate, not multi-bounce global illumination. Atmosphere is bounded, shared-depth-clipped corridor absorption/scattering approximated after tonemapping in display space; it is not full volumetric transport. Microdamage and additional effects were secondary. Explicit allocation estimate 142,389,328 GPU bytes plus 8,294,400 CPU ImageData bytes excludes browser/driver internal allocation. Raw file size is not a memory budget.

The lack of hardware affects performance and motion verification, not the observed static lighting shortcomings. Do not label this candidate artistically complete. No observatory/hangar overhaul, second artistic iteration, or post-review image adjustment was performed. Issue #1 stays open; further corridor work requires owner authorization.
